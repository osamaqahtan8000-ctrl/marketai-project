# MarketAI - المنصة الذكية للتجارة الإلكترونية والتسويق

منصة تجارة إلكترونية متكاملة تجمع بين إدارة المتاجر وتقنيات الذكاء الاصطناعي التوليدي، بهدف تمكين التجار من إنشاء وإدارة الكتالوجات وتوليد المحتوى التسويقي آلياً.

---

## 📌 مميزات المشروع الأساسية

1. **استوديو الذكاء الاصطناعي (Gemini AI Studio):**
   - توليد أوصاف تسويقية احترافية للمنتجات بدقة عالية.
   - استخراج الكلمات المفتاحية المتوافقة مع معايير محركات البحث (SEO Tags).
   - صياغة منشورات مخصصة لمنصات التواصل الاجتماعي تتضمن الهاشتاقات المناسبة.

2. **إدارة المنتجات والكتالوج (Storefront & Catalog):**
   - إضافة المنتجات وحفظها في التخزين المحلي للمتصفح (`localStorage`).
   - عرض المنتجات في بطاقات تفاعلية تشمل الصور، والتصنيفات، والأسعار.
   - شريط بحث فوري مع فلاتر ديناميكية حسب التصنيف.

3. **سلة المشتريات والدفع الفوري (Cart & Checkout):**
   - واجهة جانبية متحركة (Drawer) لإدارة عناصر السلة.
   - تعديل الكميات واحتساب إجمالي الفاتورة آلياً.
   - محاكاة عملية الدفع وتأكيد الطلب.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **الواجهة الخلفية (Backend):** Python 3, FastAPI, Uvicorn, Pydantic.
- **نموذج الذكاء الاصطناعي:** Google Gemini API (`gemini-3.1-flash-lite`).
- **الواجهة الأمامية (Frontend):** HTML5, JavaScript (ES6+), Tailwind CSS.
- **إدارة الحالة والبيانات:** LocalStorage API.
